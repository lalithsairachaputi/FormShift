ABOUTTHE PIPELINE

A generic summarizing prompt doesn't know a press advisory's dateline and contact block from a technical brief's methodology section — and it can't tell you when it has invented a detail the source never stated. This pipeline treats format and fact-checking as first-class steps, not afterthoughts.

  • 01 Extract the source article's facts and claims into a structured representation, not raw text.
  • 02 Generate the chosen format — press advisory, technical brief, or a fourth format inferred live from a few examples.
  • 03 Validate the draft's structure against that format's real schema — headline, dateline, body, contact — checked with Pydantic and JSON Schema.
  • 04 Run every generated claim back through an NLI fact-consistency model, and flag anything that can't be traced to the source.
